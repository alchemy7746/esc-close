# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use GitHub's private security advisory feature instead of opening a public issue for vulnerabilities. Include reproduction steps, affected macOS and WeChat versions, and any relevant diagnostics.

EscClose intentionally avoids network code, telemetry, dynamic library injection, and private WeChat APIs. Changes that introduce any of these should be treated as security-sensitive.
